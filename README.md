# 高槻 moo fc — 少年サッカークラブのサイト（制作サンプル）

**⚠️ 高槻 moo fc は実在しないクラブです。** Anchor Base の自主制作サンプルとして、
少年サッカークラブのサイトを一から設計・制作したものです。
クラブ名・所在地・連絡先・コーチ名・在籍数などはすべて架空です。

- **公開URL**: https://maro4120.github.io/moo-fc-top-proposal/
- **ブランチ**: `main`（GitHub Pages の公開元）
- 検索エンジンには載せない設定（`noindex, nofollow`）

---

## 構成の狙い

入団を検討している保護者が知りたい4つを、スクロールの早い位置に順番に置いています。

1. 今も募集しているか
2. うちの子は対象か
3. どこで、いつ、いくらか
4. どんな人が教えるのか

あわせて、**申し込みボタンを画面下に固定**して、どこを読んでいても押せるようにしています。

### Instagram 連携

活動写真の枠は **Instagram の投稿をそのまま表示する**構成を想定しています。
サイト側の更新作業を増やさずに、常に最新の状態に見せるのが狙いです。

## デザイン方針

エディトリアル／スポーツポスターの文法で構成しています。

- **配色**: ヘッダーは白、本文は黒 `#0D100E`。**青 `#0B4FE0` を基調色**とし、
  "地"ではなく"点"としてのみ使用（ボール、コーン、ラベル、募集ステータス）。
  **オレンジ `#F27405` は申し込みボタン専用**、**赤 `#E23A2E` はロゴのみ**と役割を固定しています
- **書体**: 英字ディスプレイ **Anton**（極太・ポスター的）／和文 **Noto Sans JP 900**
  ／ラベル・数字 **Archivo**。見出しは「英字を大きく・和文を小さく添える」型で統一
- **角丸ゼロ**（`border-radius: 0`）、**中央寄せなしの全左揃え**、1pxの細い罫線で区切る
- 数字（創設年・在籍数）を図版サイズで扱う
- スクロールで要素が立ち上がる（IntersectionObserver・約20行、`prefers-reduced-motion` 対応）

## 写真の差し替え

写真は `img/` にファイルを置くだけで反映されます。**ファイルが無い間は自動でSVGが表示される**
仕組み（`background-image` を使っているため、未配置でも壊れたアイコンは出ません）。

| ファイル名 | 内容 |
|-----------|------|
| `img/hero.jpg` | ヒーロー背景（指導する場面・`act-5` と共用） |
| `img/act-1.jpg` | TRAINING（マーカーコーンとボール） |
| `img/act-2.jpg` | GOAL（シュートを打つ選手） |
| `img/act-3.jpg` | DRILL（ボールを蹴る選手） |
| `img/act-4.jpg` | SPRINT（ボールを追う子どもたち） |
| `img/act-5.jpg` | PITCH（ピッチ全景） |
| `img/act-6.jpg` | TEAM TALK（コーチと子どもたち） |
| `img/coach-1.jpg` 〜 `coach-4.jpg` | コーチ紹介（**未配置。SVGのアバターを表示中**） |

写真はいずれも Unsplash の素材を **長辺1600px・JPEG品質82% に縮小**して配置しています
（元データは合計18MBあり、そのままでは表示が重すぎるため）。

素材のルール：

- ⚠️ **Getty Images・Unsplash+ など、透かし入りのプレビュー画像は使用できません**
- Unsplash（無料枠）/ Pexels / photoAC / ぱくたそ など、**商用利用可**が明示されたものを使う
- **実在の選手・実在のリーグと特定できる写真は使わない**（架空クラブのサイトとして矛盾するため）

## 技術メモ

- 素の HTML / CSS。JavaScript はスクロール表示の約20行のみ
- **1ファイルでレスポンシブ対応**。ヘッダーはナビ・TEL・ボタンの必要幅に応じて
  **900 / 1000 / 1180px** の3段階で切り替え
- Q&A の開閉は `<details>` / `<summary>` で実装（JS不要）
- ロゴは SVG スプライト（`<symbol>` / `<use>`）
- **320 / 360 / 375 / 414 / 600 / 768 / 900 / 1000 / 1180 / 1440px の10幅**で、
  横スクロール・要素のはみ出しがないことを確認済み
- Web フォント: Anton / Archivo / Noto Sans JP（Google Fonts）
