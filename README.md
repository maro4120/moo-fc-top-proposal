# MOO FC トップページ改善案（自主制作）

**⚠️ MOO FC は架空の少年サッカークラブです。実在の団体・施設とは関係ありません。**
団体名・住所・連絡先・写真・活動日・費用・指導者名は、すべて架空のものです。

---

## これは何か

Anchor Base（ほめまろ）が作成した、**トップページの画面イメージ**です。
「少年サッカークラブのサイトを、入団検討中の保護者向けに組み直すとどうなるか」を
自分で課題設定して作った自主制作です。

- **ブランチ**: `main`（GitHub Pages の公開元）
- 検索エンジンには載せない設定（`noindex, nofollow`）

## 設計の狙い

入団を検討している保護者が知りたい4つを、スクロールの早い位置に順番に置いています。

1. 今も募集しているか
2. うちの子は対象か
3. どこで、いつ、いくらか
4. どんな人が教えるのか

あわせて、**申し込みボタンを画面下に固定**して、どこを読んでいても押せるようにしています。

### Instagram 連携という想定

少年サッカークラブは Instagram を継続更新していることが多いため、
**その投稿をトップページに自動表示する**構成にしています。
サイト側の更新作業を増やさずに、常に最新の状態に見せるのが狙いです。

## 技術メモ

- 素の HTML / CSS のみ。JavaScript なし
- Q&A の開閉は `<details>` / `<summary>` で実装
- 375px 実機幅で横スクロールが出ないことを確認済み
- Web フォント: Noto Sans JP / IBM Plex Sans（Google Fonts）
